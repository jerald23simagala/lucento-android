# Lucento launch film: voiceover script

The master film is cut to work **without** narration. Music and on-screen headlines carry it, which also suits
autoplaying, muted feeds (Facebook, Instagram, TikTok, YouTube previews).

No natural-sounding voice generator was available here, and a robotic voice would cheapen the film, so none was
rendered. If you want a narrated version, record this script (or hire a voice artist) and send the WAV. It drops into
the composition as one `<Audio>` track at frame 0; the timings below line up with the edit.

**Voice:** warm, calm, intelligent, confident. Unhurried (about 2.3 words a second). Smiling but not salesy.
Philippine English is welcome: the film is peso-first.

## Why each line is safe to say

These are checked against the code (see `../LAUNCH_VIDEO_FEATURE_DISCOVERY.md`):

- **"see every bill coming"** and **"bills on schedule"** describe the Scheduled page and the in-app bell. They don't promise notifications, which don't exist.
- **"in the cloud"** is cloud sync, which is Pro (covered by the end card).
- **"worked out from your own records"** is how on-phone Ask Lucento answers work ("Calculated on this phone"). The line doesn't claim AI.
- **"works even offline"** is true: every core feature works offline.
- **Sharing and other currencies** are Pro. The end card says "Some features require Lucento Pro."
